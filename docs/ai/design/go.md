# Go: implementation plan (lint first)

Decided by the user: parser tree-sitter-go, primary lint tool revive (default rules). Formatting is not built now: gofmt ships with Go, and the format leg keeps its own scored row. Done when revive's default set is at 85% on the real-world group (hugo, prometheus, kubernetes, Go standard library; 47,459 findings) and the language meets the usability bar of CLAUDE.md for lint.

Each phase ends with one finish run and a landing; a checkpoint (C) stops for the lead.

## What the measurement says
98.8% of 19,887 files parse; 236 of 243 failures are Go 1.26 `new(expr)`. 91% of the findings come from five rules: exported (15,691), unused-parameter (14,178), var-naming (10,923), package-comments (2,355), redefines-builtin-id (1,042). Rules that need types (var-declaration, unexported-return, context-keys-type, time-naming) are 0.9% and stay `gap` (`needs types`). "Needs only its own file" was judged per rule; each is confirmed in revive's source before it is built.

## Phases
1. **Language.** Grammar, registration, parity runner, corpus script, support row. `new(expr)` fixed in a documented grammar fork with a test; the other 7 failures fixed or in bugs.md. No formatter: Ruby already has a verbatim formatter (`docs/ai/formatting/ruby.md`): the shared `VerbatimFormatter` is Ruby's and Go's, and Ruby's own copy goes. Corpus links under `tests/conformance/` stay untracked by a gitignore entry that also matches a symlink, so a landing never adds them. **C1:** hand back before landing (the cost check stops a new crate): list each hand-written Rust line of lang-go and say which language fact it is.
2. **Scopes.** `scope.rows` for Go (the shared scope tables; no Go code beyond the 11-line `ScopeLang` the other languages have). Unused parameter: `scope_rules/unused.rs` follows ESLint's `args: after-used`; revive reports every unused parameter, so this is an option value of the shared rule, not a second rule. `redefines-builtin-id`: the shared shadowing check plus the table of predeclared names (language data). Blank identifier, named results, function types, method expressions and closures are fixtures.
3. **Doc comments.** `exported` is three checks: missing comment (shared family `missing-doc-comment`, extended by "visible by the case of the first letter" and by comments that are the line comments directly above, with no blank line between), wrong first word (shared `doc-comment` family, new check `first-word`), stuttering name (shared names check: type name starts with package name). `package-comments` uses the shared directory facts (silent when a file of the directory was not read). Revive skips test files, main packages for some checks, a list of common method names and unexported receivers: facts in the rule's YAML. **C2:** before building, one table: revive's behaviour per check, the shared family, the param added, and the second language that could use it.
4. **Names.** `var-naming`: the shared `naming-convention` family gets a word convention (no underscores, no ALL_CAPS) and the option `initialisms` (a list with revive's values); it must not fork into a Go rule. `receiver-naming`: consistency across the methods of a type plus the generic names `this` and `self`; check in revive's source whether it looks at one file or the package. Package-name checks.
5. **Rest.** indent-error-flow and superfluous-else (`simplify` rows), empty-block (shared pattern), dot-imports, blank-imports, context-as-argument, increment-decrement, error-strings, error-naming, error-return, range, errorf (pattern files), unreachable-code (flow rows of Go: goto, labelled break, panic, `for {}`). Order by findings; stop at 85% plus what is already cheap.
6. **Generalization step** of adding-a-language.md, performance rows (parse, lint), docs, VS Code.

## Rules for every phase
Comparison on the same line; a wrong extra finding counts against us, so the number of Sudsy-only findings of each rule is reported with its share. Sudsy preset `revive` mirrors the default rule set. Suppressions `//revive:disable*` and `//nolint` go through the shared ignore mechanism. A family param that only Go uses is a plain option of the shared family; a new data format needs a second language. Rules newly on by default: +40% of Go lint is free of budget only until the first rules have landed.
